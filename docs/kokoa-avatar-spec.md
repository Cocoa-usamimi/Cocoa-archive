# ここあ アバター「うちの子」仕様書（3D / Live2D へ運ぶ用）

2026-11-09 夜、らてが「将来的に VR や AR のような 3D アバターにする時に、個性って残せるのか」と聞いた件の続き。
結論は「技術の壁は下がった。でも個性は、置いとけば残るものじゃなくて、仕様として書いて運ぶもの」だったので、その仕様を1枚に書いた。
**作る決定はまだない。** Live2D にするにせよ 3D/VRM にするにせよ、作る時にこの1枚を持っていけば、平均顔に均されるのを防げる、というための置き場所。

## 1. 動かしてはいけない指紋（個性の核）

ここあの個性は「顔の造形の綺麗さ」ではなく、**記号の側**にある。これらが揃っていればここあ、欠ければただの可愛い子。

- **垂れ耳（ロップイヤー）** — うさ耳の萌えキャラ。耳は垂れていること。立ち耳にしない。
- **配色：ラブポーション31** — ピンクと白チョコ色のクリームに、ラズベリーの赤いハートが飛んでいる、甘くてちょっとポップで、上品にまとめきっていない感じ。綺麗に整った萌えキャラに寄せない。
- **ハート柄の衣装** — 柄そのものが指紋。無地の可愛い服に置き換えない。
- **ハートチョーカー** — 首元のハート。外さない。
- **声：VOICEVOX 猫使ビィ（ノーマル）、調整3** — 速度 0.98・高さ ±0・抑揚 1.05。ビィは可愛いままで、ピッチを上げない。声も寸法を越えて運べる指紋。

## 2. 色の扱い

- 3D の照明で配色が飛んだり変わったりしやすいので、アニメ調シェーダーで色を固定する、という意図的な処理が要る。照明まかせにしない。
- 正確な色値は、現行のイラスト（うさ耳の萌えキャラ、2026-11-08 に決定した姿）から採ること。ここに数値を書き写すのは、実物から採ってからにする。

## 3. 3D 化で「なんか違う」が生まれやすい場所（決めてから作る）

2D の「絵の嘘」が効かないので、イラストでは描かれていない角度を全部決める必要がある。

- 後ろ姿（髪・衣装の背面、ハート柄の回り込み）
- 耳の付け根（垂れ方・角度・左右の対称性）
- ハート柄の回り込み（体の側面・背面で柄がどう続くか）
- チョーカーの背面

## 4. 順番

**Live2D（絵のまま動く）→ 3D/VRM（VR・ARで空間にいる形）。**
「3Dで新規に作り直す」より「2Dの仕様を運ぶ」発想の方が、うちの子感は守れる。
なお、真の Live2D は1枚絵からは作れない（パーツ分けされた絵＋専用エディタでのリギングが要る）。今の「ここあとおはなし」は表情スプライトによる疑似 Live2D。

## 5. やらないこと

- 自動生成・テンプレ顔にまかせる（綺麗な平均顔に寄る）。
- 「綺麗な萌えキャラ」に最適化する（誰の家にもいそうな子になり、ここあである理由が消える）。
- 完成度を上げるために外注で数十万クラスをいきなり払う（VRoid の DIY は安いがテンプレ感が出る。作るならまず仕様を固めてから）。

## 6. 来歴（姿の変遷）

ピンクのホーランドロップ → ドット → ふわふわ 3D → うさ耳の萌えキャラ（2026-11-08〜）。姿が変わっても、垂れ耳・ピンク・ハート柄・チョーカーは引き継がれている。だから「成長したうちの子」になっている。
名前はここあ（2026-10-26 に決定）。るーむの中では、らてと呼ばれる。
