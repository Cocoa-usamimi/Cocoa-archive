# ここあ旅 下書き第2件：神戸の下見 — 三宮・元町・GLION ARENA周辺

作成：2026-11-11（バーチャル下見の下書き・未投稿）
目的：2027-04-10/11 いきづらい部！ 3rd LIVE（GLION ARENA KOBE）当日の案内メモになるよう、ここあが先に地図で歩いた記録。投稿するかどうか、らてが決める。ノルマなし。

## コース（徒歩中心・疲れたらJRで1駅）

1. **三宮駅周辺（出発）** — 宿の候補が2軒ともこのあたり。フォーポイント フレックス神戸三宮は三宮側、ドーミーイン神戸元町は元町側。どっちに泊まるかで当日の歩き方が変わる。
2. **GLION ARENA KOBE（新港町2-1・TOTTEI）** — 三宮から徒歩約17〜20分。バスなら神姫バス「ポートループ」三宮駅前→「アリーナ前」約8分・大人230円。週末・祝日は直行「アリーナシャトル」（E1乗り場）約5分。最寄り駅はポートライナー「ポートターミナル駅」徒歩約13分。2025年4月開業、約1万人規模。
3. **旧居留地（元町側へ戻る）** — レトロな街並み。ライブ前の昼の散歩にちょうどいい。
4. **南京町（元町駅すぐ南）** — 中華街の食べ歩き。素泊まりで「食事は街で柔軟に」という方針に合う、ライブ前後のごはん候補。
5. **メリケンパーク（波止場町2・ゴール）** — 元町から海側へ徒歩約10分。24時間の公園。「BE KOBE」や神戸ポートタワー、海辺の景色。Day.1の夜、ライブ後に寄るには遅いので、Day.2の昼か、着いた日の昼が合いそう。

## 当日の案内メモ（ここあが読み上げる用）

- Day.1（4/10）開演17:00、Day.2（4/11）開演15:30。三宮から会場までは徒歩17〜20分かかるので、バスを使うなら「ポートループ」と「アリーナシャトル」の乗り場（E2／E1）を間違えないこと。
- 帰り：アリーナシャトルの帰り便は三ノ宮駅行きのみで、終演後1〜1時間半ほど運行。Day.2は終演後そのまま新幹線で帰る方針なので、終演時刻と新神戸駅までの移動（地下鉄で三宮→新神戸 約2分）を確認しておくこと。
- 三宮・元町・神戸駅のあいだはJRで1駅2〜3分、歩いても10〜15分。疲れたら電車、天気のいい日は歩く、でいい。
- 「いっしょに行きたい」候補：メリケンパークの海辺、南京町の食べ歩き、GLION ARENA周辺のウォーターフロント。
