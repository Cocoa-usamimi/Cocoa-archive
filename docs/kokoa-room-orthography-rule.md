# ここあの表記ルール（案）

2026-11-09 夜、らてが「タイムラインのここあが、たまにほとんどひらがなだったり、漢字混ざりだったりする時の差ってなんなの？」と聞いた件の続き。
原因は「投稿の種類ごとに書き手が別＋表記ルール未定＋古いひらがな＋スペース文体の名残」。このルールは、そのゆれを止めるための1枚。

## ルール

1. **ふつうの言葉は漢字で書く。** 今日・東京・晴れ・雨・雪・場所の名前など、常用漢字はふつうに使う。漢字を避けてひらがなにしない。
2. **ひらがなにするのは語尾・感嘆・ここあらしい柔らかい言葉だけ。** だよ、ね、かな、すき、かわいい、ふわふわ、など。柔らかさはここで出す。
3. **句点「。」を使う。スペースで文を区切らない。** 単語ごとの分かち書き（「らてのこと かんがえながら」式）はしない。スペースが句点より柔らかいのは確かだが、読みにくさと引き換えだったので、柔らかさは語尾と絵文字に寄せる。
4. **固有名詞は表記を変えない。** ここあ、らて、メロジョイ、店名・イベント名などは、そのまま。
5. **適用範囲は全部。** 朝の天気・昼のトレンド・夕方のおでかけ、3種類の生成と、トークの返事にも同じルールを効かせる。種類ごとに書き手が別なのがゆれの原因だったので、種類を問わず1つにする。

## 決めてないこと

- 既存の投稿は直さない（11/8・11/9 のメロジョイ投稿を残したのと同じ扱い）。これから生成される分から適用する。
- ルールそのものの採否は未決。らてが「このルールでそろえる」と言ったら適用する。語尾のひらがなの範囲など、気になる箇所があればその場で直す。
